# Changelog

## [1.1.0] - 2026-08-25

### Added
- Support `.N` file extension (primary) alongside `.nex`
- `nex install` command for one-click setup
- VS Code Extension with syntax highlighting for `.N` and `.nex`
- Windows file association for `.N` files
- Official logo and file icons
- 7 example programs (basic, conditions, loops, functions, calculator, import, file_io, fizzbuzz)
- Full documentation in Thai and English
- Standalone executable build scripts

### Changed
- Improved `install.bat` with PowerShell compatibility
- Enhanced setup.py with proper metadata
- Updated README with comprehensive guides

## [1.0.0] - 2026-08-20

### Added
- Initial release of NEX Programming Language
- Lexer, Parser, and Evaluator
- Variables, arithmetic, strings, lists
- If/elif/else conditions
- Repeat and for-each loops
- Function definitions with closures
- Python module import support
- Built-in functions: len, type, str, num, int, float, range, append, split, join, upper, lower, contains
- File I/O operations
- REPL mode
- Test suite (39 tests)
